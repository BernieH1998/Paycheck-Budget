PAYCHECK BUDGET — FREE IPHONE WEB APP

1. Create a free GitHub account.
2. Create a PUBLIC repository named paycheck-budget (GitHub Pages on the free plan uses a public repository).
3. Upload index.html, manifest.webmanifest, sw.js, icon-192.png and icon-512.png to the repository root. Do not upload private bill backups.
4. In repository Settings > Pages, choose Deploy from a branch, main, /(root), and Save.
5. Visit https://YOUR-USERNAME.github.io/paycheck-budget/ in iPhone Safari.
6. Tap Share > Add to Home Screen > Add.
7. Import your private JSON or CSV bill backup from inside the app.

The website code is public, but bills entered or imported into the app are stored locally on that device, not uploaded to GitHub. There is no automatic synchronization between devices. Export backups frequently.
